# 🚄 Деплой на Railway через Docker

Это самый простой способ деплоя - Railway автоматически соберёт Docker образ и запустит бота.

## 📋 Что включено

- ✅ Оптимизированный Dockerfile для Railway
- ✅ Health check endpoint (требование Railway)
- ✅ Автоматическая перезагрузка при ошибках
- ✅ railway.toml конфигурация
- ✅ .dockerignore для уменьшения размера образа

## 🚀 Быстрый деплой (5 минут)

### Шаг 1: Подготовка (1 минута)

1. Получите токен у @BotFather в Telegram
2. Создайте GitHub репозиторий и загрузите туда файлы:
```bash
git init
git add .
git commit -m "Ticket to Ride Europe Bot"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### Шаг 2: Создание проекта на Railway (2 минуты)

1. Перейдите на **[railway.app](https://railway.app)**
2. Нажмите **"New Project"**
3. Выберите **"Deploy from GitHub repo"**
4. Авторизуйте Railway в GitHub (если нужно)
5. Выберите ваш репозиторий с ботом

**Railway автоматически обнаружит Dockerfile и railway.toml!**

### Шаг 3: Настройка переменных (1 минута)

1. В проекте на Railway перейдите во вкладку **"Variables"**
2. Нажмите **"New Variable"**
3. Введите:
   - **Name**: `BOT_TOKEN`
   - **Value**: `ВАШ_ТОКЕН_ОТ_BOTFATHER`
4. Нажмите **"Add"**

### Шаг 4: Деплой (1 минута)

1. Нажмите **"Deploy"**
2. Railway начнёт сборку Docker образа
3. Через 1-2 минуты бот будет запущен
4. Статус должен быть **"Deployed"**

### Шаг 5: Проверка (1 минута)

1. Найдите бота в Telegram по username
2. Напишите `/start`
3. Если бот отвечает - всё работает! 🎉

## 📊 Мониторинг

## 🆘 Решение проблем

### ❌ "Build failed"
**Причина**: Ошибка в Dockerfile или requirements.txt
**Решение**: 
- Проверьте логи сборки
- Убедитесь, что все файлы загружены
- Проверьте requirements.txt

### ❌ "Bot not responding"
**Причина**: Бот не запускается или крашится
**Решение**:
- Проверьте логи в Railway
- Убедитесь, что BOT_TOKEN корректный
- Проверьте health check endpoint

### ❌ "Token was rejected"
**Причина**: Неверный токен
**Решение**:
- Получите новый токен у @BotFather
- Обновите переменную BOT_TOKEN
- Перезапустите бота

### ❌ "Health check failed"
**Причина**: Бот не отвечает на health check
**Решение**:
- Проверьте, что порт 8080 доступен
- Проверьте логи на ошибки
- Убедитесь, что Flask сервер запущен
