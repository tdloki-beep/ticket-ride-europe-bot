# Ticket to Ride: Europe Telegram Bot

Telegram-бот для игры в Ticket to Ride: Europe с поддержкой русского языка и AI-оппонентами.

## 🎮 Возможности

- 🗺 Полная карта Европы из Ticket to Ride: Europe
- 🤖 Игра против AI-бота с продуманной стратегией
- 👥 Мультиплеер до 5 игроков
- 🎨 Визуализация карты и карт игроков
- 📱 Удобный Telegram-интерфейс на русском языке
- 🎯 Прогноз ходов бота

## 🚀 Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте токен бота:
```bash
cp .env.example .env
# Отредактируйте .env и добавьте ваш BOT_TOKEN
```

4. Запустите бота:
```bash
python bot.py
```

### Запуск через Docker

1. Создайте файл `.env` с токеном бота
2. Запустите:
```bash
docker-compose up --build
```

## 🤖 Команды бота

### Основные команды

- `/start` - Приветствие и помощь
- `/newgame` - Создать новую игру
- `/join` - Присоединиться к игре
- `/startgame` - Начать игру
- `/rules` - Правила игры

### Игровые команды

- `/map` - Показать карту Европы
- `/hand` - Показать свои карты
- `/status` - Статус игры
- `/draw` - Взять карты вагонов
- `/claim` - Захватить маршрут
- `/routes` - Взять карты маршрутов

### Дополнительные команды

- `/bot` - Добавить AI-бота в игру

## 🎯 Как играть

1. **Создайте игру**: `/newgame`
2. **Пригласите друзей**: Игроки используют `/join`
3. **Добавьте бота** (опционально): `/bot`
4. **Начните игру**: `/startgame`
5. **Играйте по очереди**:
   - Берите карты: `/draw`
   - Захватывайте маршруты: `/claim`
   - Берите карты маршрутов: `/routes`

## 🤖 Стратегия бота

AI-бот использует адаптивную стратегию:

- **Агрессивная**: Стремится к длинным маршрутам
- **Баланс**: Сочетает захват и сбор карт
- **Адаптивная**: Реагирует на действия соперников

Бот прогнозирует свой следующий ход и показывает его игрокам.
